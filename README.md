## About

VoiceMaestro creates temporary voice rooms on demand and gives room owners tools for privacy, naming, access control, automation, and cleanup.

VoiceMaestro is **free-first**. Normal bot features are available without a paid unlock.

## Features

- Join-to-create temporary voice channels
- Owner controls for lock, unlock, rename, limits, trust, block, transfer, and more
- Optional interface message for button-based room management
- Automation tools for idle handling, auto-delete, and role flows
- Voice activity tools, presets, and permission templates

## VoiceMaestro+

VoiceMaestro+ is an **optional supporter membership**.

It does **not** unlock normal bot features. It helps support hosting, uptime, development, bug fixes, and future improvements for everyone.

Supporter benefits:

- Supporter role in the official support server
- Community recognition
- Direct support for hosting and ongoing development
