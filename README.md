# VoiceMaestro

**VoiceMaestro** is a powerful and easy-to-use Discord bot designed to manage dynamic voice channels. It allows users to create their own temporary voice channels and manage them with a simple, user-friendly interface.

---

## 🚀 Features

- **Dynamic Voice Channels**: Automatically creates voice channels when users join a "Hub" channel.
- **User Management**: Users have full control over their own channels.
- **Moderation Tools**: Lock, unlock, hide, and limit user access.
- **Customizable**: Rename channels and set user limits on the fly.
- **Interactive Interface**: Control everything via simple buttons or slash commands.

---

## 🛠️ Commands

### **Setup & Configuration**
- `/setup create` - Create the "Join to Create" voice hub system.
- `/setup delete` - Remove the voice hub system.
- `/interface` - Set up the voice channel interface (text channel with buttons).
- `/delete interface` - Delete the voice interface.

### **Channel Management**
- `/channel` - Create a temporary voice channel (Premium options available).
- `/lock` - Lock your voice channel (prevent new users from joining).
- `/unlock` - Unlock your voice channel.
- `/hide` - Hide your voice channel from the list.
- `/reveal` - Reveal your voice channel.
- `/rename <name>` - Change the name of your voice channel.
- `/limit <number>` - Set a user limit for your channel (0-99).
- `/bitrate <kbps>` - Set the channel audio quality.
- `/video_quality <hd/sd>` - Toggle HD video quality.

### **User Access**
- `/permit <user>` - Allow a specific user to join your locked channel.
- `/reject <user>` - Kick a user from your channel and prevent them from re-joining.
- `/claim` - Claim ownership of a channel if the previous owner left.
- `/transfer <user>` - Transfer channel ownership to another user.
- `/trust <user>` - Trust a user (allow them to manage the channel).
- `/untrust <user>` - Revoke trust from a user.
- `/block <user>` - Block a user from joining your channel.
- `/unblock <user>` - Unblock a user.

### **Premium Features**
- `/premium` - Check subscription status.
- `/panel` - Open the interactive voice control dashboard.
- `/dashboard` - View your premium statistics and settings.
- `/automation` - Configure auto-delete, auto-roles, and idle timeouts.
- `/voicestats` - View your voice activity leaderboards.
- `/presets` - Save and load voice channel configurations.

### **Utility**
- `/stats` - View bot statistics (Server count, Ping, Uptime).
- `/ping` - Check the bot's response time.
- `/help` - View the help menu.
- `/support` - Get links to the support server and website.
- `/activity` - Start a voice channel activity (e.g., YouTube Together).
