## Overview

VoiceMaestro creates temporary voice channels on demand, then gives room owners tools for access control, privacy, naming, limits, and cleanup.

VoiceMaestro is **free-first**. Core bot features are available without a premium unlock.

VoiceMaestro+ is an **optional supporter membership** that helps cover hosting, uptime, development, bug fixes, and future improvements.

## Core Features

- Join-to-create voice channel system
- Owner controls for lock, unlock, rename, limit, transfer, trust, and block
- Optional interface message for button-based room management
- Automation tools for idle handling, cleanup, and role flows
- Voice stats, presets, and permission templates
