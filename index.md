## What VoiceMaestro Does

VoiceMaestro creates temporary voice channels on demand (Join-to-Create), then gives channel owners a clean interface to manage them:

- Lock / unlock
- Hide / reveal
- Rename
- Set user limits
- Permit / reject access
- Block / unblock users
- Claim / transfer ownership (where enabled)
- Optional UI (buttons + dashboards)

---

## Getting Started

1. Run `/setup create`
2. (Optional) Run `/interface` to create the control panel
3. Need commands? → See **[Commands](/commands/)**
